# Project structure

- `sql/`: original SQL source from the conversation.
- `power_bi/`: Power BI connection and dashboard instructions, plus starter DAX.
- `reports/`: editable Markdown report draft; export to PDF after adding verified results.
- `docs/`: SQL caveats and GitHub publishing steps.
- `data/exports/`: optional safe CSV exports.
- `screenshots/`: dashboard screenshots after you create them.
